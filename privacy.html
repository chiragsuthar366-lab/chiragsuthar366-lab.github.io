Privacy Policy

Last updated: August 2026

This application is a personal content-publishing tool built and operated by an individual developer ("the operator"). It is used only by the operator, to publish the operator's own video content to social media accounts the operator owns.

What data this application handles

This application processes the operator's own video files, captions, and metadata, and the operator's own API credentials for connected platforms (including YouTube, Instagram, and TikTok), solely to publish that content to the operator's own accounts.

What this application does not do

This application does not collect data from, or about, any third party or end user. It has no public sign-up flow, does not serve other users' data, and does not sell, share, or transfer any data to any third party.

Data storage

Credentials and content are stored using each connected platform's own secure secret-storage mechanisms and are used only for the automated publishing described above.
